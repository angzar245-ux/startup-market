# Исследование рынка стартапов: динамика финансирования и возвратность инвестиций

## Бизнес-задача

Инвестиционному фонду нужно было определить наиболее перспективные сегменты рынка и типы финансирования для долгосрочных вложений. На основе исторических данных о 54 000+ стартапах требовалось выявить закономерности в динамике финансирования, оценить возвратность разных типов инвестиций и сформулировать рекомендации по инвестиционной стратегии.

## Данные

- **Основной датасет:** `cb_investments.csv` — 54 294 компании, 40 признаков (название, отрасль, объём и число раундов, даты первого/последнего финансирования, суммы по типам финансирования и раундам).
- **Дополнительный датасет:** `cb_returns.csv` — 15 строк, 14 столбцов (суммы возвратов по типам финансирования в млн USD по годам).
- **Связь:** таблицы независимы, анализ ведётся по годам и типам финансирования.

## Инструменты

- Python: `pandas`, `numpy`, `matplotlib`, `seaborn`
- Jupyter Notebook

## Что сделано

1. **Предобработка:**
   - очистила текстовые поля от лишних пробелов, привела `funding_total_usd` к числовому типу;
   - обработала пропуски: заполнила заглушками категориальные, заполнила `mid_funding_at` серединой интервала между `first_funding_at` и `last_funding_at`;
   - удалила полные дубликаты и строки без данных о финансировании;
   - итоговый датасет: **40 906 строк** (удалено ~25% «шумных» записей).

2. **Инжиниринг признаков:**
   - разделила компании на три группы по срокам финансирования (единичное, до года, более года);
   - классифицировала сегменты рынка на массовые (>120 компаний), средние (35–120) и нишевые (<35).

3. **Работа с выбросами:**
   - применила метод IQR отдельно по каждому сегменту;
   - исключила компании с аномальным финансированием и годы с менее чем 50 раундами.

4. **Анализ:**
   - сравнила типы финансирования по суммарному объёму и популярности;
   - построила динамику медианного размера раунда и общего количества раундов по годам;
   - выделила массовые сегменты с ростом финансирования в 2014 году;
   - рассчитала нормированную возвратность (отношение возвратов к инвестициям) по годам и типам финансирования, заменила аномальные значения на пропуски.

## Ключевые результаты

- **Структура финансирования:** 58.9% компаний имеют только один раунд, но привлекают лишь 30.6% всех инвестиций. Компании со сроком финансирования более года (30% от числа) аккумулируют **61.9% всех инвестиций**.
- **Сегменты с ростом в 2014 году:** Healthcare, Software, E-Commerce, Cloud Computing, Big Data, Internet — все массовые (>120 компаний), что снижает риск «единичного провала».
- **Возвратность по типам финансирования** (средняя нормированная, без выбросов):
  - Post-IPO Equity: 57.2%
  - Private Equity: 45.8%
  - Angel: 41.7%
  - Debt Financing: 35.5%
  - Seed: 28.5%
  - Venture: 22.0%
- **Устойчивый рост возвратности** — у Angel и Private Equity: плавное увеличение без резких обвалов.

## Рекомендация для бизнеса

1. **Фокус на Healthcare** и смежные технологические подсегменты (Software, Big Data, Cloud Computing) — быстрорастущие и массовые.
2. **Для долгосрочных вложений — Private Equity** (возвратность ~46%, устойчивый рост) **или Angel** (~42%, но требует опыта работы с ранними стадиями).
3. **Debt Financing** — компромиссный вариант с умеренным риском и возвратностью ~36%.
4. **Seed и Venture** более волатильны — подходят для инвесторов, готовых к высокому риску и длительному сроку окупаемости.
